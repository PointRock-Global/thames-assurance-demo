# Thames Assurance — Live Demo

Clickable partner demo for the Thames Water Project Assurance UI (demo data only).

**Open the site:** https://jidecraig01.github.io/thames-assurance-demo/

Flow: Login → **Sites Portfolio** (6 sites) → Beckton / Oxford Ground Truth boards → full site rail. Map and regions remain available from the rail.

Local: `python3 -m http.server 8765` from this folder, or `./start.sh` / `start.bat`.
